SCENE 5

型＝入れ物の種類

int整数。90/60 は 1（切り捨て）
long大きな整数。社員ID 1001L
booleantrue / false。締め済み？
String文字。比べるのは equals
BigDecimalお金。double だと誤差が出る
LocalDate日付だけ。勤務日
LocalDateTime日付＋時刻。出勤時刻
Duration時間の長さ。実労働時間

黄色はつまずきやすい型。小文字始まりは null にならない。
