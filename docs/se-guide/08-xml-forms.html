SCENE 1

SCENE 2

XMLは箱の入れ子

開けたら閉じる。内側から順に閉じれば壊れない。

SCENE 3

タグ・属性・値を見分ける

<field①
  id="route"②③
  required="true">
  経路④
</field>
1青＝タグ。箱の名前
2白＝属性。箱に貼るラベル
3緑＝値。必ず "" で囲む
4中身。画面に出る文字

SCENE 5

XML↔画面↔DBをつなぐ

(A) field

<field id="route" required="true"/>
  • 画面：入力欄「経路」＊必須
  • DB：通勤手当の route 列

(B) options

SELECT transport_nm
  FROM m_transport
  • 画面：プルダウン「交通手段」
  • DB：交通手段マスタを読むだけ

(A) check

<check min="1" max="100000"/>
  • 画面：赤いエラー表示
  • DB：なし（保存前に止める）

(C) route

<step name="上長承認"/>
<step name="人事承認"/>
  • 画面：承認者の受信一覧
  • DB：組織・権限マスタ

(D) onComplete

UPDATE t_commute_allowance
   SET route = #{route}
  • 画面：なし（裏で動く）
  • DB：通勤手当テーブルを更新
  • #{route}＝画面の route の値
SCENE 6

SQLの < はCDATAで守る

そのまま書く 
<sql>
 WHERE a <= b
</sql>
< をタグと勘違い→画面ごと開かない
→
CDATAで囲む 
<sql><![CDATA[
 WHERE a <= b
]]></sql>
中は「ただの文字」になる
<&lt;
>&gt;
&&amp;

CDATAの外ではこの書き方（エスケープ）に置き換える。

SCENE 7

申請中のデータ差戻し中の申請が残っていないか先に数える
構文チェックxmllint やエディタの赤い波線で確認
差分を見るWinMerge・git diff で変えた所だけか確認

まずテスト環境ラベル1文字の変更から試す
