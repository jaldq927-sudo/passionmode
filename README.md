# WEMOF - Wakkyai's Entry Model Of FX
## TradingView Pine Script インジケーター

わっきゃい氏考案の逆張りスキャルピング手法「WEMOF」のTradingView用Pineスクリプトです。

---

## ファイル構成

| ファイル | 説明 |
|---|---|
| `WEMOF.pine` | メインインジケーター（価格チャートにオーバーレイ） |
| `WEMOF_PercentB.pine` | %Bサブチャート（オプション・別途追加） |

## 手法概要

**WEMOF = Wakkyai's Entry Model Of FX**

ボリンジャーバンド±3σ付近の**「説明できない異常な動き（気持ち悪い相場）」**に対し逆張りエントリーを行うスキャルピング手法。

> 「順張りは期待で打つ。逆張りは結果で打つ」（ジュン著『チリが積もって15億』）

### 重要: 単純な3σタッチ ≠ WEMOFシグナル

| 条件 | 判定 |
|---|---|
| ニュース・要人発言による急動き | スキップ（説明可能）|
| 三角持ち合いのブレイク | スキップ（説明可能）|
| ラウンドナンバー付近の動き | スキップ（説明可能）|
| 直近高値・安値のブレイク | スキップ（説明可能）|
| ピボットポイント付近 | スキップ（説明可能）|
| **理由が見当たらない急動き** | **WEMOFシグナル候補！** |

## インジケーターの仕組み

### 使用指標

1. **ボリンジャーバンド ±3σ**（SMA20ベース）
2. **%B**（±3σ基準。わっきゃい氏が異常検知に使用）
3. **日次ピボットポイント**（PP / R1 / R2 / S1 / S2）

### シグナル2段階構造

```
段階1 [準備 △▽ 黄色三角]:
  HighまたはLowが±3σにタッチ + %B変化量が大きい + 説明不可
  → 「さらに超えてきたら逆張り準備」

段階2 [WEMOFシグナル ラベル矢印]:
  終値が初めて±3σをブレイク + %B変化量が大きい + 説明不可
  → 「逆張りエントリー検討」（ニュース確認後）
```

### 自動フィルター（説明可能性チェック）

| フィルター | 説明 |
|---|---|
| ラウンドナンバー | JPY系: 150.00円単位, Non-JPY: 0.0100単位 |
| 直近高安値ブレイク | 過去N本の高値・安値を更新した場合 |
| ピボット付近 | 日次PP/R1/R2/S1/S2から指定pips以内 |

> ⚠️ **ニュース・要人発言・チャートパターンは自動フィルター不可！必ず手動確認してください。**

## セットアップ方法

### 1. メインインジケーター追加

1. TradingViewを開く
2. USD/JPY 5分足チャートを表示
3. Pine Editorを開く（画面下部）
4. `WEMOF.pine` の内容をペースト
5. 「追加」ボタンでチャートに追加

### 2. オプション: %Bサブチャート

1. 新しいインジケーターとして `WEMOF_PercentB.pine` を追加
2. WEMOF.pineと同じBB期間・閾値に設定

## アラート設定（無料プラン対応）

TradingViewの無料プランは**アラート1枠のみ**ですが、このスクリプトは**1つのアラートでロング・ショート・準備すべての通知**に対応しています。

### 設定手順

1. チャートにWEMOF.pineを追加
2. 画面右上の時計アイコン（アラームを追加）をクリック
3. **条件**: `WEMOF - Wakkyai's Entry Model Of FX` を選択
4. **条件の種類**: `Any alert() function call` を選択
5. 通知方法（メール・プッシュ通知等）を設定
6. **「作成」をクリック**

### アラートメッセージ例

```
[WEMOF LONG/BUY] USDJPY | 終値: 149.850 | -3sigma: 149.920 | %B変化: 0.42 | !! ニュース・テクニカルを確認してからエントリー !!

[WEMOF SHORT/SELL] USDJPY | 終値: 151.120 | +3sigma: 151.080 | %B変化: 0.38 | !! ニュース・テクニカルを確認してからエントリー !!

[WEMOF準備-LONG] USDJPY | -3σ到達: 149.920 | 終値がさらに下を超えたらロングエントリー検討 | !! ニュース・テクニカル確認を !!
```

## 推奨設定

| 項目 | 推奨値 |
|---|---|
| 通貨ペア | USD/JPY |
| 時間足 | 5分足 |
| BB期間 | 20 |
| %B変化閾値 | 0.30（厳格にしたい場合は0.35〜0.40）|
| ラウンドナンバーバッファ | 10 pips |
| 高安値ルックバック | 20バー |
| ピボットバッファ | 15 pips |
